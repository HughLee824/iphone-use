# Agent 文字操作流程优化（2026-10-02）

本轮针对 `.6` 短上下文试用中的重复观察、重复准备键盘、命令探索和诊断阅读成本。底层 HID、媒体协议、屏幕保护阈值和光标算法未改动，不自动重放未知输入。

## 实现

- canonical skill 与两种客户端指引补上标准模式文字流程。准备键盘一次；读取每个动作附带的有效观察；确认文字后完成当前剪贴板事务；下一次输入复用 `text-finish` 返回的观察。拒绝帧也可直接读取，不无条件再 `observe`。
- Codex 开始命令与后台续读模板在命令完成后，同一次工具调用内显示 JSON 和附带 PNG。即使退出非零、输入结果未知或未派发，仍读取成功返回的观察。读取图片失败只恢复读取，不能重复动作。
- 新增可选 `--agent-output`，适用于动作、`text-prepare` 和 `text-finish`。完整回执保存在私有临时目录；输出保留动作结果、错误、恢复指引、剪贴板事务及观察，合并重复的媒体采样诊断。直接字段像素匹配不再需要读者解释 `fieldTemporalMatch=false`；摘要显式区分全屏、字段和保护区域差异。默认 JSON 接口、退出码及设备请求保持兼容。
- preflight 一次检查观察/摘要/模式能力；显式候选包可用 `--candidate`，源码用 `--source`，`IPHONE_USE_CLI` 可指定含空格路径。继续沿用 `IPHONE_USE_CONFIG_DIR` 环境变量，不新增配置命令参数。
- 同步项目插件副本并纠正指引中将签名/setup 视为标准模式前提的表述。未替换本机旧插件、未发布新版插件或候选包，原 `.6` 不变。

## 验证

- Swift 宿主测试：369 项，1 项既有可选检查跳过，0 失败；新增 7 项回执摘要测试，覆盖未知结果、恢复状态、直接/时序字段匹配、拒绝归因、私有完整回执、保存失败时保留原结果。
- Python 开发测试：53 项通过，含 CLI 假服务集成、默认接口兼容、选项不进入设备请求、附带观察不产生额外请求，以及插件打包/preflight。
- Codex JavaScript 模板测试：17 项通过，含分段续读、未知结果与拒绝的即时图片读取、图片失败保留原命令结果，以及 shell 字面参数。
- Release 构建、源码 preflight、插件同步、diff 空白检查通过。
- Skill 结构校验：当前 Python 缺少 PyYAML，临时安装遇到 TLS 证书验证失败，未关闭证书验证。使用 macOS Ruby 的安全 YAML 解析器适配同一未修改的官方校验脚本，通过前置元数据与正文检查。这不代表独立 Agent 行为验收。

首轮 Python 的新增大回执假服务测试失败，回执为 Network.framework 读取时的 `Network is down`。假服务发送完立即关闭连接，增加等待读端消费后关闭解决测试竞态；复跑上述 53 项通过。未为此修改产品传输代码。

## 历史回执离线重放

将上次 Probe 的准备、一次拒绝、replace、append、恢复共 5 份响应中的结果和观察，经本地假服务送入新 CLI 输出层。没有连接设备，也没有派发输入。每份仅一个宿主请求，完整结果和观察引用保留；这里使用的旧排除区域不代表认可其选择。

按相同 JSON 编码归一化计算的大小（含摘要和回执路径）：

| 响应 | 完整回执字节 | 摘要回执字节 |
| --- | ---: | ---: |
| 准备键盘 | 2,036 | 2,279 |
| 输入前拒绝 | 5,257 | 3,414 |
| replace | 7,275 | 4,534 |
| append | 7,358 | 4,608 |
| 恢复剪贴板 | 1,665 | 1,945 |

三次输入回执减少约 35%–38%；原本短的准备/恢复响应因增加摘要与路径略有增大。拒绝正确归因为全屏变化 1.4946% 超过 1%，字段直接像素匹配。两次已排队输入仍报告 `unknown`，没有被摘要改写为执行成功。
