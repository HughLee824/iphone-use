# 原生字段局部比较与光标排除验收

2026-10-03。实现 `field-edge-temporal-caret-v2`，替换单一透明度重建。详细规则与可见性限制见[光标处理](native-text-phase-matching.md)。没有提高全屏 1% 阈值，没有放宽 Agent 视频排除框与输入字段的互斥规则，没有增加用户配置或第三方依赖。

## 改动

完整字段保留原像素坐标和原观察；优先严格匹配，再检查受限的既有边缘差异与小噪声块。颜色无关的 A–B–A 周期确认固定窄竖条后，只排除该区域及固定两个原生像素边缘；区域外仍检查完整字段，区域内原图须与观测光标／背景颜色范围相容。可见光标移动、宽选区和文字变化有拒绝回归。隐藏光标的不可见移动及视觉完全等价的内容变化无法单凭截图保证识别。

回执新增 `fieldAppearanceMatch` 和通过时的 `caretRect`，简明输出区分 `pixels`、`appearance`、`temporal`、`different`。低层派发结果保持 `unknown`，不因视觉保护通过就改为输入成功，不重放输入。

## 离线证据

复用 `.8` 的真实失败序列，原字段框和视频排除框保持不变。在不包含基准图本身的 13 个六帧回放窗口中，新实现每个窗口都能找到匹配。此前 `readonly-phases-v2/prepare.png` 的两个窗口均六帧全拒绝；现在分别在第 1、第 3 帧出现局部外观匹配。另三组中间光标相位序列在第 4 帧出现时序光标排除。

剩余静态非边缘残差的实测为 13 个低幅像素（差值 9–11），分布为单点或两像素相邻小块。新规则不是直接接受一定面积内的任意差异：强差异拒绝；既有边缘必须在两图同一位置满足邻域对比度条件；其他噪声按连通块及总量受限。尺寸超过 2×2 原生像素的连通低对比度新笔画仍拒绝。规则阈值是工程边界，不是任意微小文本变化均可判别的承诺。

14 张仅含受控 Probe 输入框、无设备或页面元数据的裁剪 PNG 纳入 `Tests/IPhoneUseCoreTests/Fixtures/NativeText`，宿主回归无需研究目录或真机。在这些原图上注入细笔画、低对比度笔画、删除文字和选区，均拒绝；图片改写工具的无改动回读另有测试，防止图像方向错误制造虚假反例。
