# 动画排除边缘的面积采样修正

2026-10-03。修正 `.7` Probe 验收中的边缘误拒绝：保留 Agent 指定的排除矩形，不自动扩大范围，不提高容差。

## 原因与实现

此前 `srgb-grid-excluded-rect-v1` 将排除框外的四块区域裁剪后，交给 CoreGraphics 高质量插值缩小成粗网格。插值并非逐面积平均；动画残留的一圈原生像素可能被抽样成整格差异。新增合成回归在 1170×2532 PNG 上，仅漏出一像素宽的动画边缘就计算出 1.9802% 的全屏变化，超过 1% 阈值；旧实现下该回归确实失败。

新的 `srgb-area-excluded-rect-v2` 在同一裁剪区域内按原生像素整数边界分配网格，每格读取全部像素、计算 sRGB 整数平均。原生像素只参与一个格子的均值，末尾余数也被计入。每个区域最多读取 1600 万像素，超限拒绝，避免无界内存分配。

修改仅作用于有显式排除框的全屏比较。没有排除框时仍为 `srgb-grid-v1`；完整字段逐像素比较、48×48 保护区域、光标周期判定、颜色容差 8、全屏 1%、局部 0、25% 排除面积上限与几何互斥检查均不变。忽略框仍不包含相邻保护区域；相邻控件的局部变化不能因均值被隐藏。光标采样仍只在全屏检查通过后继续，不跳过真正的页面变化。

算法名称变化使不支持 v2 的旧 Runner 在输入前拒绝；需要配套 Runner，不能对旧 wire 指纹使用新解释。报文没有加入原生尺寸截图，现有请求预算不变。
