# 输入事务内的有界只读收敛校验

2026-10-24。修复设置搜索输入已执行、末尾 frame 校验碰到键盘过渡而返回 unknown 的问题。原因与原始时间序列见 [设置搜索诊断](runner-settings-search-diagnosis.md)。实现不包含 App 或页面特判。

## 最终行为

- 初始执行前仍严格验证原始完整路径、AX 身份和属性。普通的输入前检查不等待、不修改基准。
- 聚焦、光标定位、清空和插入之后，在输入事务内部执行只读验证；仅 `target_geometry_changed` 可重新读取。每阶段最多 5 秒、6 次完整解析，读取间隔最多 100 ms。
- 几何变化不会立即截断路径检查：先完成所有路径节点身份和非几何属性检查、精确绑定、绑定叶节点复核以及新根完整路径复核。任一步身份、路径或关键属性不符，立即停止，不被祖先 frame 的变化掩盖。
- 每次重查均重新请求快照、绑定同一个观察期 AX 身份；没有复用旧树来宣告成功，没有更换目标。全部 frame 仍须回到观察时基准，误差不超过 0.5 pt。
- 返回最后一次根快照中的目标叶节点，用于后置值校验，避免使用更早的绑定叶快照。替换/追加仍须确认清空和最终完整值。
- 不重放聚焦、光标定位、删除或插入。输入失败、身份改变、值不符等错误不被通用重试吞掉。超出预算返回 `text_geometry_unsettled`，保留执行事实。
- `textExecution` 新增累计 `convergenceReads`、`geometryRetries`、`convergenceTimedOut`，以及最近一次收敛阶段耗时 `convergenceElapsedMs`。读取数可以跨多个阶段累计超过 6；单阶段上限仍是 6。
- CLI 与 Runner 的 `actionVersion` 同步升至 12，拒绝将旧 Runner 当作具备本次行为的版本。

5 秒是读取调度和成功判定的期限，不是中断 Apple 同步调用的硬实时保证。单次平台调用若阻塞超过期限，返回后不再继续读取，也不接受超时到达的成功结果；外层已有传输超时仍生效。
