# Apple 原生设备后端：实现交接

日期：2026-09-19。设计依据：[修订方案](apple-native-device-control.md)。本交接授权开始实现，而非继续重复 AX 可行性实验。

## 目标与第一阶段

为普通第三方 iOS App 实现不依赖 XCTest Runner 的观察与控制后端：Apple 原生截图 → Agent 选择坐标 → 自写 HID 执行 → 新截图验证。先打通纯原生服务连接、媒体会话与 tap 闭环（方案 M2–M3），按需补齐 M1 的最小观察契约。

第一阶段应交付可运行代码和相关验证，不只提交接口、空适配层或新的调研总结。如果某个 Apple 接口存在明确权限或协议阻塞，完成独立可推进的部分，保留失败证据，准确说明未验证项；不得用第三方客户端或 Runner 偷换验收。

## 必须保留的约束

- 使用 Apple CLI、系统/Xcode 框架和自写 Swift/C/Objective-C 代码。不得执行或引入 go-ios、pymobiledevice3、WDA 等设备工具；第三方项目只能参考原理。
- 保留已有 Apple 官方 swift-argument-parser，不借本任务做无关依赖清理。
- 新原生后端不得启动 Runner 或隐式回退至现有 XCTest 后端。现有发布后端先保留，避免破坏用户流程；如何选择新后端按当前代码的最小可维护方式实现。
- AX 不在首版必需链路中。不得用焦点遍历获取“当前屏幕树”，因为它会滚动；本阶段不再测试新的 App/AX 按钮。
- 不伪造 Apple 身份、entitlement、可信事件或修改系统保护。目标设备必须由发现/配置提供，不硬编码研究机标识。
- 不进入聊天、发送消息、改变系统或账户设置作为测试。优先受控 Probe；需要解锁或信任时再说明具体阻塞。
- 原始设备截图、协议日志、签名信息留在忽略的本地目录，不提交为公开测试 fixture。

## 已确认的研究结论

- 当前研究环境：macOS 27.0 (26A428)、Xcode 27.0 (27A266a)、iPhone 12 Pro / iOS 27.0 (24A437)，Developer Mode 开启。
- devicectl 截图和 App 启动有成功证据，但 launch 回包不总等于前台已切换。黑屏和旧图片不能成为有效观察。
- HID 点击、滑动和简单英文输入存在历史成功记录，但使用过第三方协议实现，且不是升级后纯原生 HID 的工程验收。
- 自写原生 AX 客户端已成功，不等于自写原生 HID 已完成。普通 App 的部分语义可读，但已有 Activate 无效果；严格无焦点读取未取得完整视口树。
- 官方 MCP 的已查真机入口和自写 remoteAXService 入口有明确限制，不继续盲目重试，不把符号当作可调用 SDK。
- 历史 RemoteXPC 多请求有回复通道问题；新连接只是实验规避。必须处理请求编号/回复关联。
- 历史 stopAll 会影响其他媒体会话，不能进入生产清理；同连接健康、媒体保活、会话归属和断连后不重放均需验证。
- 英文样例不等于通用文字输入；中文/输入法、长按/拖拽、录屏、实时解码保持后续独立验收。

## 实施顺序与验收

1. 核对当前仓库和工具链，运行有意义的既有测试基线。明确可复用的进程、设备发现、图片和会话代码。
2. 完成最小原生观察：唯一产物路径、解码校验、设备/方向/尺寸/采集时段、observationID；保留裁剪/缩放转换来源。
3. 解决纯原生服务发现/连接和媒体生命周期。建立自写 fake transport，验证请求回复关联、超时、取消、资源所有权和清理。
4. 实现单指 tap：新观测绑定、坐标变换、contact/release、串行执行和异常释放。过期观察拒绝派发；未知结果不自动重放。
5. 在连接的受控真机上证明真实效果，核对动作前后截图/受控计数，记录准确版本、依赖和进程。不要用 status=0 或截图变化代替正确命中。
6. 运行改动相关测试和项目要求的检查，整理实现、验收和剩余风险。保持每个提交范围清晰；不要顺便提交私人研究目录或发布版本。

新增测试围绕协议关联、坐标转换、陈旧观察、未知结果不重放与清理等真实风险；无需为文档或简单可逆包装堆积镜像实现的测试。真机受阻时不把模拟测试标成真机通过。

## 本机证据与隔离工作区

方案第 11 节索引了原始本地报告。`.local/` 不入 Git，也不会自动出现在新 worktree。启动任务会提供原 checkout 的绝对路径，必要时从原路径只读查看证据；不要把第三方研究目录加入新客户端的搜索路径，不执行其中的第三方脚本。

本阶段不要求重新采集所有 AX 数据、不扩展支持矩阵、不引入 OCR 或实时视频。只有新的证据表明它们直接阻塞最小闭环时，才重新评估范围。
