# 原生文字基准与光标修复

## 问题和行为

两种已复现的机制会把未变的文字拒绝为过期观察：

- 媒体开流初期，静态文字的重建像素会演变。固定早期截图作为基准后，继续等待不能消除两者的差异。同一码流的 Apple 硬件/禁用硬件解码、重复转换和 PNG 导出一致；本次没有定位发送端具体量化参数，也没有取得历史 `.9` 请求的原始流。
- 光标判定原先要求整条细线的 RGB 变化方向一致。真实 Apple PNG 显示，局部背景不同时，光标不同位置可以有相反的 RGB 变化方向。字段其余像素相同，旧代码仍拒绝。

`text-prepare --field-rect x,y,width,height` 在生成**新观察之前**建立稳定文字基准，可用字段外的 `--ignore-rect` 排除视频。候选需要两次后续比较支持，证据跨度至少 0.6 秒；最多采十帧、保留六个候选，媒体阶段预算三秒。不能建立基准时，返回绑定 Apple PNG 来源的新观察。预算不包括 Apple 截图和锁屏/显示检查。无字段的旧调用兼容，不承诺局部稳定性。

带字段的 type/press 以及其 text-finish 后续观察沿用该检查，不要求每次重新 prepare。执行前仍核对原 observationID、原截图来源及完整字段，不替换旧基准。独立协议操作 `text-prepare-scoped` 使旧宿主明确拒绝新请求，避免静默忽略字段。

光标新增逐像素、相对于原观察的淡入淡出检查，要求变化方向的比例关系和一致的淡入/淡出次序；不限制光标颜色。真实 A–B–A 周期、窄矩形边界、完整字段比较和源像素范围检查保留，像素/面积阈值不提高。新增笔画和移动细线仍拒绝，未知输入结果不重放。

使用方式见 [动作说明](actions.md)；Agent 调用说明及仓库插件副本已同步。

## 验证

2026-10-03，macOS 27.0 / Xcode 27.0，Apple 动态发现的 iPhone 12 Pro / iOS 27.0：

- 71 项相关 Release 宿主测试通过，包括基准有界采样、真实 PNG 回归、文字变化/移动光标负例及宿主观察关联。这不是完整测试套件。
- CLI 集成 20 项、插件测试 8 项通过于对应接口改动阶段；之后仅光标算法与测试改动，未重复宣称执行这两组测试。
- 受控 Probe 真机完成 prepare → 中文 replace → 剪贴板恢复 → 中文 append → 剪贴板恢复。五条命令累计约 17 秒（不含 Agent 思考），全部返回媒体截图。目视结果分别为 `稳定基准验证🙂` 和 `稳定基准验证🙂；追加通过✅`，编辑计数依次 15→16→17。
- 两次输入协议结果仍为 `unknown`，成功依据是截图中的实际文字；没有重放。剪贴板恢复确认，自有键盘、媒体、接收器和隧道清理确认，宿主进程退出。
- Probe 定时改变字段后，变化前观察上的输入约 1.05 秒返回 `not_dispatched`，未发送测试字符。该场景同时有字段外汇总变化，字段单独负例由宿主测试覆盖。

首轮真机仅加稳定基准时仍失败：Apple PNG 兜底正常，但光标误拒绝使第六帧匹配落在八秒预算外。只读补采确认变化限于光标 6×57 原生像素；修正后真实回放识别范围约 3.33×20.33 点。该失败保留在本地证据中，不算成功验收。

七个新增受控字段 PNG（相同字节的返回相位去重）是上述两个缺陷的最小回归序列，来源、尺寸和边界见 [fixture 说明](../Tests/IPhoneUseCoreTests/Fixtures/NativeText/README.md)。未提交全屏截图、原始视频流、剪贴板内容或设备标识。

完整本地报告、原始帧和回执留在被 Git 忽略的 `.local/research/media-pixel-drift-20261003/` 与 `.local/research/text-baseline-validation-20261003/`。后者 `submission-archive/` 保存精简前报告和未入库图片。本次没有消除媒体协议源头的压缩漂移，也不代表所有 App、重建场景或光标样式均已验证。未发布或推送远端。

## Apple PNG 相位采样补齐（2026-10-03）

后续备忘录试用再次暴露采样预算问题：原观察年龄为 26.73 秒；每次 Apple PNG 都重复前后锁屏/显示检查，三次字段比较仍不匹配，累计 9.08 秒超过 8 秒预算。保留的渲染图可见光标显隐变化。没有证据将其归因于 30 秒观察过期，也不能只凭缩放图断言原始像素的全部差异。

已将 Apple PNG 输入前校验改为一次前后锁屏/显示检查之间的有界相位采样，最多六帧，仍固定原 observationID、截图来源和字段；每帧检查原比较器，匹配或全屏变化超限即停止。每个截图命令使用剩余预算，最终检查和派发仍不得超过原时限。记录 `appleTextPhaseSamples`、实际帧数和累计截图耗时。未更改颜色规则、像素/面积阈值、真实 A–B–A 要求，也未允许静态细线消失直接通过。

验证：新增五项 Apple 采样宿主测试和 92 项关联测试通过（合计 97 项不同测试，非全套）；覆盖晚返回相位、无闪烁证据、正文变化、来源变化、锁屏/方向/取消及期限拒绝。在同一已授权临时备忘录中，用自写只读探针直接调用修复后的 AppleDeviceCLI 和 NativeInputPreflight，三轮为 2.31 / 5.19 / 3.71 秒，分别采 1 / 3 / 2 帧且在预算内匹配；后两轮先出现字段不匹配，再匹配原观察。没有输入文字或使用剪贴板，退出编辑后确认自有会话清理。

以上三轮只验证采样，未输入文字。完整回执、原尺寸截图、自写探针和日志留在忽略目录 `.local/research/apple-text-phase-20261003/`，不提交新 PNG。
