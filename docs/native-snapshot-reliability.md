# 原生截图可靠性与黄色光标修复

日期：2026-09-26。接续[备忘录真实 App 验收](standard-notes-workflow.md)。本次修复保护链路中的确定缺陷，并隔离尚未定位的媒体失真；不宣称已经确定上次残影的根因。

## 观察来源

标准模式从会话开始就使用 Apple PNG，涵盖独立 observe、动作前保护与动作后观察。`captureSource=coredevice_screenshot`，`captureSourcePolicy.strategy=coredevice_only`，原因 `media_snapshot_validation_pending`。新的会话、媒体恢复出帧和调用方的来源偏好都不能启用媒体像素；Apple 截图失败时返回错误，不使用媒体图掩盖失败。

原生媒体仍维持既有所有权、保活、方向同步与录屏。观察时继续核对媒体几何与方向，但不再为最终不会采用的媒体帧生成 PNG。Apple 截图前后的锁屏、显示信息、取消和最终图像检查保持。旧媒体观察进入输入前保护时仍按来源变化拒绝，不能跨来源比较后自动输入。

这是暂时牺牲部分截图速度的可靠性措施。媒体重新成为观察来源之前，需要可重放的失真证据、对应修复和真机验证；零解码错误、媒体健康或重新连接后正常均不足以撤销此限制。Runner 截图实现不变。

## 媒体依赖链

代码与宿主回归确认：接收中出现序号缺口，同时 RTP 时间戳改变时，原组帧器先标记损坏、再切换单元，后者会清除前者的标记。后续收到的残缺 IDR 单元可能因此被放行。现在切换单元后再应用本包的序号缺口，丢弃受损单元及后续依赖帧，直到新的完整 IDR。该重组器同时供原生录屏使用。对同一组合成包运行修改前后代码：旧实现放行受损 IDR，新实现拒绝并等待关键帧；这证明确定缺陷已修复，但不是本轮真机残影的根因证明。

截图解码分支还增加以下处理：

- 组帧丢弃、序号不连续或畸形负载会立即清空缓存截图、重置解码引用链，保留已收到的参数集以等待关键帧恢复。
- 不递增的视频时间戳不再静默跳过后沿用旧解码器，而是使当前解码 generation 失效；队列中旧 generation 的包不能继续产出截图。参数集独立单元和正常时间戳回绕仍允许。
- VideoToolbox 回调标记 `frameDropped` 时拒绝该输出，即使 OSStatus 为零。
- 状态增加 `droppedUnits`、`discontinuities`、`malformedPackets`、`timestampRejections`、`referenceResets` 与 `waitingForKeyframe`。这些是协议/解码处理事实，不等同于图像正确性保证。

原观察的新鲜度约束仍保留：整帧首包在请求后，消费时年龄不超过 0.5 秒，最多等待 0.15 秒。没有使用旧帧填补空缺，没有自动重连或重放输入，也没有使用 stopAll。

## 黄色光标

原生完整字段保护现在允许从原图识别蓝色或 Notes 风格黄色光标。黄色候选使用有限颜色范围；仍要求唯一、宽 1–3 points、高 8–40 points、占有率至少 85% 的竖线及均匀周围背景。同一原位置只允许一致的明暗变化，完整字段其他像素仍按原始分辨率检查。

原图光标不可见、多个候选、选区、移动、正文变化、背景变化和颜色不支持时不启用例外。局部阈值仍为零，全屏仍为 1%，观察时效和剪贴板前后保护不变；不新增 type 容差参数。回执算法名为 `source-blue-yellow-caret-fade-v2`。Runner 的动作后判稳显式保留原有蓝色范围，不随本次原生输入修复扩张。

## 验证与边界

Debug 与 Release 构建通过，Release CLI 版本命令可运行。宿主完整 Swift 回归执行 321 项，320 通过、1 项既有可选检查跳过，零失败。覆盖 Apple 图优先于可用媒体、Apple 失败不得改用媒体、锁屏/方向/取消检查、实际画面变化拒绝、跨时间戳丢包、异常时间戳恢复，以及黄光标淡入淡出与正文/选区/位置变化反例。

随后为明确隔离 Runner 的颜色范围补充了定向回归：24 项通过、零失败。动作观察与模式 CLI 契约测试另外 23 项通过。宿主通过不等同于 Notes 追加通过。

本轮重新发现唯一有线 iPhone 后，Apple 返回 `passcodeRequired=true`；因此尚未发送新触控、粘贴或访问剪贴板。正在等待用户解锁，新的媒体故障采集和 Notes 默认参数追加尚未真机验证。

上次保留的媒体 PNG 重放可定位部分黄色光标，但光标外存在压缩像素差异，完整字段仍拒绝；没有为通过该样本放宽噪声阈值。Notes 的验收需使用本次 Apple PNG 路径。
