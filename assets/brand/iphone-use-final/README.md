# iphone-use · Logo 规范稿

以本轮选定的最新版本 `iphone-use-logo-a-balanced-v2` 为基础，保留已调整好的弧线位置。主标和横向字标与该版本逐字节一致。本次补齐规范展示、B式制图、复建脚本与验证记录。

## 设计与识别

竖向圆角块面和顶部胶囊构成手机线索；屏幕内的等宽圆头弧线表达连续滑动。已移除触点，避免对单次操作进行过多图示。弧线的位置延续用户逐次校正的视觉平衡，没有为了网格或整数比例重新居中。

设计者语义自查：手机与滑动均有具体形态线索，但弧线也可能被理解成抽象曲线。此处是设计意图，不代表外部识别率。未进行外部人员识别测试或印刷打样。

## 几何规范

本坐标系原点在160×160画布左上，x向右、y向下。以下均为本次设计参数，不是对生成位图的测量推断。

| 部位 | 参数 |
| --- | --- |
| 手机外框 | 左上(43,18)，宽74、高124，四角R17 |
| 顶部胶囊 | 左上(71,29)，宽18、高6，端圆R3 |
| 滑动弧线 | 圆心(44,64)，中心线R54，起角0°、终角70°，顺时针 |
| 弧线宽度 | 9；内侧R49.5、外侧R58.5，端圆R4.5 |
| 模数 | x=9，即弧线宽度；外框宽74/9 x，高124/9 x |
| 主色/反白 | #171717 / #F5F5F2 |
| 字标 | 保留Geist Medium 500路径字形，无字体安装依赖 |

主标为单条闭合复合路径，使用evenodd规则构成两个真实透明孔。无白色覆盖、蒙版、位图、滤镜或自由曲线。主图中的曲面由真实圆弧构成；制图圆均对应外角、胶囊或轨迹的实际构造关系。

建议外轮廓之外至少保留一个模数（9单位）安全区。不要非等比缩放。横向组合可整体等比缩放，不单独移动其中的图标或字形。

## 实际验证与使用限制

设计定稿时已运行 `verify.py`，并检查实际渲染；可按下文步骤重新生成这些检查产物：

- 主标和字标与最新选定版逐字节一致；制图和展示复用主路径。
- 在独立临时目录从参数重新构建，6个SVG逐字节一致。
- 轨迹宽度恒为9，端圆相切点积残差为0，外圆角未挤占直边。
- 对1282个轨迹边界采样点计算圆角外框内部净距，采样最小值为14.5单位。该值是采样检查，不冒充连续曲线的全局解析证明。
- 正黑/反白PNG的alpha一致；生产SVG无字体、位图、滤镜或遮罩依赖。
- alpha≥128、前景8邻域/背景4邻域下，24、32、48、64和1024px均保留一个实体组件、两个孔洞。
- **16px未通过孔洞连续性检查**：弧线负形发生像素分段，不建议将此母版直接用于16px。当前建议最小画布为24px，32px以上细节更充分。

几何检查、栅格化结果与识别测试分别记录；没有把机器验证描述为用户识别通过。

## 复建

从本目录执行：

```sh
python3 build.py
NODE_PATH=/path/to/node_modules node render.cjs
python3 verify.py
```

`build.py`仅依赖Python标准库；`render.cjs`依赖Node sharp；`verify.py`依赖Pillow。用 `build.py --out DIRECTORY` 可输出到新目录。脚本不绑定机器路径，也不影响iphone-use的CLI运行依赖。

此目录保存已确认的设计母版。仓库中英文README、Runner App Icon和favicon现已切换，见[生产资源说明](../README.md)。favicon仅收紧画布留白，未改动母版轮廓；16px请使用生产资源中的专用导出，不使用本目录的失败样本。
